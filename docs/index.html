cortex

A folder of notes becomes a brain you can talk to.

Point cortex at your notes — home, company, club, any activity — and chat with them on your own model. Retrieval is hybrid and cited, the model endpoint is whatever you run, and every capability is a plugin you can add without forking.

Install

Three commands to a working brain

pip install 'cortex-brain[server,mcp]'
cortex init ~/brains/home
cortex index --brain ~/brains/home && cortex chat --brain ~/brains/home

cortex init writes a commented cortex.yaml pointed at http://localhost:11434/v1 (Ollama's default). Edit the endpoint and model names to match what you actually run, drop markdown into notes/ — an Obsidian vault clone works as-is — and index. No model is needed to install; without an embedding endpoint, search runs full-text and says so.

What it does not do. cortex hosts no model — you bring an OpenAI-compatible endpoint (Ollama, vLLM, LM Studio, OpenRouter, OpenAI) or an Anthropic key. It does not crawl git forges. Vector search is exact cosine in-process: right for personal- and team-sized brains, wrong for millions of chunks.

How it works

A directory, an index, an agent loop

A brain is a folder: cortex.yaml, your notes/, connector output in sources/, and a disposable .cortex/ cache holding the SQLite index and conversation history. Back it up by copying the folder; run a second brain by running cortex init somewhere else.

index

Markdown chunks on headings (keeping the full heading path), code on definitions. Incremental by mtime+size signature. Changing the chunk schema or the embedding model re-indexes from scratch — mixing vector spaces is corruption, not compatibility.

search

FTS5 and vector cosine ranked separately, fused with reciprocal rank fusion, nudged by recency. No single scorer is trusted on its own — the design from Cerebras' knowledge-base write-up.

agent

A plain while-loop: model, tool calls, results, repeat. Streaming end to end. The prompt enforces search-before-answer, exact-grep for pasted literals, and citations by file path. Durable facts land in memory via remember.

The model is a setting, not a dependency

Provider profiles are declared in cortex.yaml and assigned roles — chat and embeddings can come from different endpoints. Two wire protocols cover the field: OpenAI-compatible and Anthropic. Endpoints are classified by network facts: private, loopback, CGNAT and Tailscale addresses are trusted; anything public gets a plain warning that your notes will leave the network, because DNS cannot prove who operates a remote host.

Extend

Four plugin surfaces, one rule: broken plugins are isolated

SurfaceContractWhen it runs
Tool plugin plugins/*.py exposing register(registry), or a package with a cortex.tools entry point agent time
MCP server mcp_servers: block — stdio or streamable HTTP; exclude wins over include agent time
Skill skills/<name>/SKILL.md (agentskills.io); the prompt lists names only, instructions load lazily via use_skill on demand
Connector connectors/*.py exposing sync(out_dir, settings); distill, don't dump — write markdown that retrieves well connectors run

Registration is not authorization: a tool that touches something sensitive keeps its own checks inside the callable.

cortex is also an MCP server

The same registry the chat agent uses exports over stdio, so Claude Code, Cursor, or Hermes can search your brain:

claude mcp add home-brain -- cortex mcp --brain ~/brains/home

Configure

One YAML file per brain

name: home
providers:
  local:
    kind: openai                  # the wire protocol, not the vendor
    base_url: "http://localhost:11434/v1"
    chat_model: qwen3
    embed_model: nomic-embed-text
  claude:
    kind: anthropic
    api_key_env: ANTHROPIC_API_KEY
    chat_model: claude-sonnet-5
roles:
  chat: claude                    # chat and embeddings can differ
  embed: local
mcp_servers:
  home-assistant:
    transport: http
    url: "http://homeassistant.local:8123/mcp"
connectors:
  calendar_ics:
    urls: {home: "https://calendar.example/private-abc.ics"}
server:
  auth: none                      # none = loopback only; key = ctx_ Bearer keys

Serving beyond localhost

With auth: none the server refuses to bind anything but loopback. On a LAN, set auth: key and issue ctx_ keys (cortex keys issue laptop) — shown once, stored as SHA-256, verified in constant time.

Measured, not asserted

Every model and tool call appends JSONL to .cortex/usage.jsonl with prompt_tokens/completion_tokens when the endpoint reports them — absent counts stay absent, which is what preflight expects. Telemetry never makes a call fail.

Lineage

What cortex borrows, and from where

The retrieval design (hybrid fusion, distill-don't-dump connectors) is carried over from Brainiac, which borrowed it from Cerebras' knowledge base. The extensibility model — built-in tools, then MCP, then skills — follows Hermes Agent. The SQLite-first storage floor exists because a home brain should not need Postgres, Qdrant, and Docker to answer a question about rosemary.
